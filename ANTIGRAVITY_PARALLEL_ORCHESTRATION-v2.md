## 🏢 2. BREAKDOWN PERAN AGENT ID & PEMBERDAYAAN TOOLS / PLATFORM PARALEL

Setiap Agen memiliki **ID Khusus**, **Stasioner Kerja Terisolasi (Git Shadow Worktree)**, serta wewenang penuh untuk mengendalikan *tools & platform* spesifik secara paralel:

### 👑 1. AGENT ALPHA (`agent-alpha-orchestrator`)
* **Identitas**: Lead System Orchestrator & Master DAG Manager.
* **Tools & Platform**: Antigravity AI IDE (`agy`), F.O.R.G.E. Framework, Liftoff Suite, Git Shadow Worktree Manager, HITL Safety Gate.
* **Fokus Operasional**:
  1. Memindai repositori proyek dan membuat peta dependensi `dependency-map.json` (DAG).
  2. Memicu eksekusi *subagent* paralel (`invoke_subagent`) ke stasioner kerja terisolasi.
  3. Mengelola konvergensi *shadow worktrees* dan verifikasi *clean commit* ke GitHub (`git push origin main`).

### 🧠 2. AGENT BETA (`agent-beta-hermes`)
* **Identitas**: Cognitive Reasoning & Persistent Memory Engine.
* **Tools & Platform**: HERMES AGENT DESKTOP APPS, Tripartite Memory (`SOUL.md`, `MEMORY.md`, `USER-v2.md`), Progressive Disclosure Engine, Skill Loop Manager.
* **Fokus Operasional**:
  1. Mengoperasikan Hermes Agent Desktop Apps untuk penalaran LLM otonom dan memori persisten lintas sesi.
  2. Mengaktifkan *Skill Loop* untuk mengompilasi prosedur kerja kompleks menjadi berkas `SKILL.md` baru secara mandiri.
  3. Mengelola *Progressive Disclosure* (Level 1: Index ➔ Level 2: Params ➔ Level 3: Full Routine) guna efisiensi token.

### ⚡ 3. AGENT GAMMA (`agent-gamma-gateway`)
* **Identitas**: AI Gateway, Token Optimization & Resiliency Router.
* **Tools & Platform**: 9ROUTER Proxy, AMRouter, OpenRouter, RTK Token Saver (-40% Token), 3-Tier Fallback Router.
* **Fokus Operasional**:
  1. Mengelola local proxy 9Router / AMRouter pada port `20128` (`/v1` OpenAI-compatible API).
  2. Mengompresi prompt dan *tool results* sebesar **20%–40%** menggunakan fitur *RTK Token Saver*.
  3. Menjaga hierarki resiliensi *3-Tier Automatic Fallback* (Tier 1: Subscriptions ➔ Tier 2: Paid APIs ➔ Tier 3: Free/Heuristic Tiers).

### ⚙️ 4. AGENT DELTA (`agent-delta-middleware`)
* **Identitas**: Ingestion, Webhook & Workflow Middleware Engine.
* **Tools & Platform**: n8n Workflow Automation (Cloud / Self-Hosted Port `5678`), Python FastAPI Server (Port `8080`), Uvicorn ASGI, Fast ACK (<150ms), RAM Session Manager.
* **Fokus Operasional**:
  1. Mengelola n8n Workflow Nodes untuk *Webhook Ingestion* kilat dengan respon `HTTP 200 OK` (<150 ms).
  2. Menjalankan FastAPI Webhook Server dan *Conversational Session Manager* (rolling buffer 15 pesan di RAM).
  3. Mengoperasikan daemon pemindai email proaktif `00-G-MAIL_BOT` berbasis IMAP/SMTP SSL.

### 💬 5. AGENT EPSILON (`agent-epsilon-messaging`)
* **Identitas**: Multi-Channel Messaging & Dual Dispatcher Worker.
* **Tools & Platform**: WHATSAPP (Meta Business Graph API v21.0 & Local Gateway Bridge Port `3000`), TELEGRAM (Telegram Bot API, `@BotFather`, Forum Topics, Mini Apps `/apps`).
* **Fokus Operasional**:
  1. Mengelola bot Telegram via `@BotFather`, merender *Inline Keyboards*, *Forum Topics/Threads*, dan Telegram Mini Apps (`/apps`).
  2. Mengatur pengiriman WhatsApp melalui kebijakan **Dual Dispatcher Failover** (Meta API ➔ *Local Gateway Bridge* Port `3000`).
  3. Menyajikan tombol aksi interaktif (`[Approve]`, `[Decline]`, `[Calendar]`) pada pesan balasan.

### 🔑 6. AGENT FARAD (`agent-farad-mcp-postman`)
* **Identitas**: Credential Gateway, MCP Router & API Lifecycle Manager.
* **Tools & Platform**: COMPOSIO MCP Gateway, POSTMAN MCP Server (146+ Tools), REST API, OAuth 2.0/2.1, Google Workspace CLI (`gws`).
* **Fokus Operasional**:
  1. Mengelola otentikasi OAuth 2.0/2.1 terenkripsi untuk 1.500+ SaaS apps via Composio MCP.
  2. Menggunakan *Just-In-Time (JIT) Tool Search* (~200 token proxy) untuk mencegah *context bloat*.
  3. Mengoperasikan Postman MCP Server untuk eksekusi API collection, validasi skema OpenAPI, dan integrasi Gmail/Calendar via `gws`.

### ☁️ 7. AGENT LAMBDA (`agent-lambda-cloud-db`)
* **Identitas**: Cloud Infrastructure, Serverless & Database Deployment Manager.
* **Tools & Platform**: RENDER Cloud Platform (`render.yaml` IaC Blueprint), VERCEL, DOCKER, FIREBASE, FIRESTORE, Managed PostgreSQL (`ipAllowList: []`).

* **Fokus Operasional**:

  2. Menyediakan jalur Webhook publik **100% Gratis tanpa verifikasi kartu kredit** untuk pengujian *live test drive*.
